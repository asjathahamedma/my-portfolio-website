# Event Management System

This web application brings event organization and ticket booking into one ASP.NET MVC project. Its main workflows cover account access, event management, booking, and administration.

## Main features

- User registration and login
- Event creation and management
- Event booking
- An admin dashboard

## Implementation stack

The application is built with ASP.NET MVC and C#. SQL Server provides the database, Entity Framework handles data access, and Bootstrap supports the interface.

## Running the project

The project is opened in Visual Studio after cloning. Restore the NuGet packages, configure the database connection string for the local environment, and run the application.

See the [project repository](https://github.com/asjathahamedma/SmartEventMVC) for the source and setup details.
